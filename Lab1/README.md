# Lab1 - Student Details Program

## Problem Statement
write a C program to accept and display a student's roll number, name, and marks.

## Approach/ Algorithm
1. Start the program.
2. Declare variables for roll number, name and marks.
3. Accept the student's roll number.
4. Accept the student's name.
5. Accept the student's marks.
6. Display all student details.
7. Stop the program.

## Time and Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Sample Input/ Output
**Input:** 
Roll number: 21   
Name: Avani   
Marks:     
 

**Output:**
Student Details  
Roll number: 21  
Name: Avani  
Marks:
