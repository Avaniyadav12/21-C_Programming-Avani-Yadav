# Lab 4 - Arrays and String Manipulation

## Introduction
This lab covers arrays, matrices, and string manipulation in C programming
through basic concepts, practice programs, and application-based projects.

## Basic Concepts
- One-Dimensional and Two-Dimensional Arrays
- Array Initialization and Traversal
- Searching and Bubble Sort
- Matrix Addition, Multiplication and Transpose
- String Input and Output
- Standard String Library Functions
- String Operations Without Library Functions

## Practice Programs
1. Largest and Smallest Element
2. Sum and Average of Array Elements
3. Linear Search
4. Bubble Sort
5. Matrix Operations
6. Reverse a string
7. Palindrome String
8. Count Vowels, Digits and Spaces
9. Frequency of Characters

## Application Programs
1. Student Marks Management System
2. Matrix Calculator
3. String Processing Tooolkit

## Analysis
1. Compare Searching Before and After Sorting.
2. Compare Library and User-defined String Functions.

## Learning Outcomes
- Learned array declaration and operations.
- Understood searching and sorting techniques.
- Performed basic matrix operations.
- Learned string manipulation.
- Developed logical thinking and problem-solving skills.
